# 📍 ביחד

אפליקציה לשיתוף מיקום הדדי בזמן אמת בין שני אנשים (אנדרואיד).

## ⬇️ הורדה

**[לחץ כאן להורדת האפליקציה (Together.apk)](https://github.com/dorcohen1one-rgb/byahad/releases/latest/download/Together.apk)**

## התקנה
1. לוחצים על הקישור למעלה מהטלפון ← "הורד בכל זאת".
2. פותחים את הקובץ ← אם הטלפון שואל, מאשרים "התקנה ממקור זה".
   בסמסונג, אם ההתקנה נחסמת: הגדרות ← אבטחה ופרטיות ← Auto Blocker ← לכבות זמנית.
3. פותחים את "ביחד" ← "יש לי קוד הזמנה" ← מדביקים את הקוד שקיבלתם.

המיקום מוצפן מקצה לקצה. רק מי שיש לו את קוד ההזמנה יכול לראות אתכם.
כל עוד השיתוף פעיל יש התראה קבועה בטלפון, ואפשר להשהות בכל רגע.
